# Bank Marketing Classification Models

This repository contains implementations of various machine learning classification models, including Logistic Regression, Random Forest, Support Vector Machine (SVM), and Gradient Boosting. These models are trained and evaluated on the **Bank Marketing dataset** to predict whether a client subscribes to a term deposit.

## Models Used:
- **Logistic Regression**: A simple and interpretable model for binary classification.
- **Random Forest**: An ensemble method that improves prediction by combining multiple decision trees.
- **Support Vector Machine (SVM)**: A powerful model for binary classification with high-dimensional data.
- **Gradient Boosting**: An ensemble method that builds trees sequentially to correct errors from previous ones.

## Dataset:
The dataset is a part of the UCI Machine Learning Repository and contains information about clients of a bank. The goal is to predict whether a client subscribes to a term deposit (`y` = "yes" or "no").

## Performance Evaluation:
The models are evaluated using the following metrics:
- **Accuracy**: The proportion of correct predictions.
- **Precision**: The ability of the model to correctly identify positive cases.
- **Recall**: The model’s ability to correctly identify all relevant cases.
- **F1-Score**: The harmonic mean of precision and recall.
- **Confusion Matrix**: A table showing the performance of the classification model.
